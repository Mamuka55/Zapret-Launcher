# 🚀 Zapret Launcher

**Zapret Launcher** — современный Windows-лаунчер для удобного управления стратегиями **Zapret** и **TG Proxy**.

Приложение позволяет запускать и останавливать BAT-стратегии в один клик, добавлять их в избранное, устанавливать необходимые компоненты и автоматически получать обновления с GitHub.

Интерфейс выполнен в современном стиле **Glassmorphism** и поддерживает настройку цветов.

![Zapret Launcher](build/icon.png)

---

## ✨ Возможности

### 🛡️ Управление Zapret

* 🔲 Отдельная плитка для каждого `.bat`-скрипта.
* ▶️ Запуск стратегии одним нажатием.
* ⏹️ Остановка запущенной стратегии повторным нажатием.
* 🟢 Запущенная стратегия подсвечивается зелёным.
* 🔎 Автоматическое обнаружение новых BAT-файлов.
* 🗑️ Удалённые стратегии автоматически исчезают из приложения.
* 🔢 Удобная сортировка стратегий.

---

### ⭐ Избранное

Любую стратегию можно добавить в избранное.

Избранные стратегии автоматически перемещаются в отдельный раздел:

```text
⭐ Избранное
```

После добавления в избранное плитка **исчезает из общего списка**, поэтому одна стратегия не отображается дважды.

Избранное сохраняется между запусками приложения.

---

### 🛰️ TG Proxy

Добавлена отдельная категория:

```text
🛰️ TG Proxy
```

TG Proxy полностью отделён от стратегий Zapret.

Поддерживается:

* 📥 установка;
* 🔄 обновление;
* ▶️ запуск;
* ⏹️ остановка;
* ⚙️ отдельные настройки;
* 🟢 независимый статус запуска.

Zapret и TG Proxy могут работать **одновременно**, при этом обе плитки могут одновременно подсвечиваться зелёным.

TG Proxy не отображается в общем списке стратегий Zapret.

Плитка TG Proxy появляется только после успешной установки компонента.

Проект TG Proxy:

https://github.com/Flowseal/tg-ws-proxy

## 📦 Установка компонентов

При запуске приложение проверяет наличие необходимых компонентов.

Если Zapret отсутствует, лаунчер предложит установить его:

```text
🛡️ Zapret не установлен
[ Установить Zapret ]
```

Если TG Proxy отсутствует:

```text
🛰️ TG Proxy не установлен
[ Установить TG Proxy ]
```

Компоненты устанавливаются автоматически.

### 📁 Расположение

Все компоненты находятся в одной директории:

```text
Documents\
└── Zapret Launcher\
    ├── zapret\
    └── tg-ws-proxy\
```

## 🔄 Обновления

Все обновления собраны в одном месте:

**Настройки → Обновления**

Доступна проверка и обновление:

* 🛡️ Zapret;
* 🛰️ TG Proxy;
* 🚀 самого Zapret Launcher;
* 🌐 Hosts;
* 🌍 IPSet.

При обновлении Zapret новые стратегии автоматически появляются в лаунчере, а удалённые стратегии исчезают.

Сам лаунчер может получать новые версии через **GitHub Releases**.

Репозиторий:

https://github.com/Mamuka55/Zapret-Launcher

---

## 🌐 Hosts

Встроена загрузка и обновление Hosts.

При проблемах с обычным сетевым запросом используется резервный способ подключения, поэтому приложение не зависит только от Electron `fetch`.

Это помогает избежать ошибки:

```text
fetch failed
```

## 🎨 Кастомизация

Лаунчер поддерживает гибкую настройку внешнего вида.

В настройках можно выбрать:

🎨 цвет интерфейса
🌈 цвет акцента

Для выбора используется полноценная системная палитра, поэтому можно установить практически любой цвет, а не выбирать только из заранее подготовленных вариантов.

Выбранные цвета сохраняются автоматически.

## 🔐 Права администратора

При необходимости Windows отображает стандартное окно UAC.
