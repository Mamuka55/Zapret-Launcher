# 🚀 Zapret Launcher

Современный **Windows-лаунчер** для управления BAT/CMD-скриптами проекта **zapret-discord-youtube**.

Приложение автоматически обнаруживает стратегии в папке `zapret` и позволяет запускать и останавливать их в один клик.

Интерфейс выполнен в стиле **Glassmorphism** с красно-серой цветовой схемой.

## ✨ Основные возможности

* 🧩 Автоматическое обнаружение `.bat` и `.cmd` файлов
* ▶️ Запуск и остановка стратегий в один клик
* 🟢 Визуальный статус активной стратегии
* ⭐ Избранное и отдельная секция избранных скриптов
* ⚙️ Единое окно настроек
* 🔄 Проверка и установка обновлений через GitHub
* 📦 Автоматическое добавление новых и удаление отсутствующих BAT-файлов после обновления
* 🛠️ Управление сервисами **zapret / WinDivert**
* 🎮 Game Filter и IPSet Filter
* 🧪 Управление fake-файлами для Discord и игр
* 🔍 Системная диагностика и поиск конфликтующих служб
* 🌐 Проверка Proxy, DoH, Hosts и других системных параметров
* 🪟 Скрытый запуск BAT без появления консольного окна
* 🔐 Поддержка запуска с правами администратора
* 🧪 Unit и Smoke тесты
* 📦 Сборка Portable и Setup `.exe`

## 🛠️ Технологии

* **Electron**
* **Vanilla JavaScript**
* **HTML5**
* **CSS3**

Проект не использует тяжёлые UI-фреймворки и построен с упором на простоту, производительность и работу непосредственно с Windows.

## 📦 Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/USER/REPOSITORY.git
cd REPOSITORY
```

Установите зависимости:

```bash
npm install
```

Запустите приложение в режиме разработки:

```bash
npm start
```

## 🧪 Тестирование

Запуск тестов:

```bash
npm test
```

## 🔨 Сборка

Для создания Windows-сборки:

```bash
npm run dist
```

После сборки доступны:

* **Portable EXE**
* **Setup EXE**

## 🖥️ Системные требования

* Windows 10 / 11
* Node.js для разработки и сборки
* Права администратора для функций, связанных с системными службами и WinDivert

## 🔄 Обновления

Launcher поддерживает обновление через GitHub.

При обновлении приложение может:

* заменить изменённые BAT-файлы;
* добавить новые стратегии;
* удалить отсутствующие стратегии;
* обновить файлы приложения.

## 📁 Работа со стратегиями

Все доступные BAT/CMD-файлы автоматически отображаются в интерфейсе приложения в виде отдельных плиток.

Избранные стратегии отображаются отдельно для быстрого доступа.
